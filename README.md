# Ensino Médio e Técnico

Repositório criado para armazenar exercícios, atividades e pequenos projetos desenvolvidos durante meus estudos de **Python**.

Os arquivos foram desenvolvidos com o objetivo de praticar lógica de programação, estruturas de dados, funções, programação orientada a objetos e criação de aplicações simples utilizando o terminal.

## Conteúdos praticados

Durante o desenvolvimento dos exercícios, foram trabalhados conceitos como:

* Variáveis e tipos de dados
* Entrada e saída de dados
* Operadores matemáticos e lógicos
* Estruturas condicionais (`if`, `elif`, `else`)
* Estruturas de repetição (`for` e `while`)
* Funções
* Listas, tuplas e dicionários
* Manipulação de dados
* Tratamento básico de exceções
* Geração de números aleatórios
* Programação Orientada a Objetos (POO)
* Classes, atributos e métodos
* Estruturas de menu
* Simulação de sistemas através do terminal

## Exemplos de exercícios e projetos

### Jogos e simulações

* `Jogo.py` — jogo de adivinhação com número aleatório e limite de tentativas.
* `casino.py` — simulação de um jogo baseado em sorteios.
* `score.py` — exercício relacionado a pontuação.
* `urna.py` — simulação simples de votação.
* `par ou ímpar.py` — verificação de números pares e ímpares.

### Exercícios de lógica e matemática

* `Fibonacci.py` — sequência de Fibonacci.
* `tabuada.py` — geração de tabuada.
* `vetor.py` — cálculo de média a partir de notas.
* `Media s11.py` — exercício envolvendo cálculo de média.
* `Salario por hora.py` — cálculo relacionado a salário e horas trabalhadas.
* `temperatura.py` — conversão e manipulação de temperaturas.
* `aposentadoria.py` — exercício relacionado à aposentadoria.
* `positivo ou ímpar.py` — exercício de lógica utilizando condições.

### Pequenos sistemas

* `Katchau.py` — simulação de uma loja de produtos de informática, com categorias, carrinho de compras e finalização de pedido.
* `menu.py` — sistema de cadastro e consulta de equipes.
* `TabelaCurso.LSS12.py` — seleção de cursos por área e nível de dificuldade.
* `saque.py` — exercício simulando operações de saque.
* `relatorio.py` — geração de informações em formato de relatório.

### Conceitos de programação

* `IOT.py` — exercício utilizando funções e um sistema de comandos para simular dispositivos.
* `poo1.py` — introdução à Programação Orientada a Objetos através de uma classe `Lampada`.
* `poo2.py` — exercício de POO utilizando uma classe `Usuario`, atributos e métodos.
* `dicionário.py` — prática com dicionários.
* `vetor.py` — prática com listas e processamento de dados.
* `lista tutorial.py` — exercícios relacionados a listas.
* `item.py` — exercício envolvendo manipulação de itens.
* `teste.py` — testes e experimentos durante os estudos.

## Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/KlebersonDuarte/Escola.git
```

### 2. Entre na pasta

```bash
cd Escola
```

### 3. Execute um dos arquivos

Por exemplo:

```bash
python Jogo.py
```

Ou:

```bash
python Katchau.py
```

Os programas que utilizam `input()` precisam ser executados pelo terminal para que seja possível interagir com eles.

## Objetivo

Este repositório representa parte da minha evolução no aprendizado de **Python e lógica de programação**.

A ideia é registrar exercícios realizados durante os estudos e utilizar esses projetos para praticar conceitos fundamentais antes de avançar para aplicações maiores e mais complexas.

## Observação

Os projetos deste repositório possuem diferentes níveis de complexidade e foram desenvolvidos principalmente para **aprendizado e prática**.

Por isso, alguns códigos podem conter implementações simples ou diferentes abordagens para resolver o mesmo tipo de problema.
